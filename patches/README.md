# patches/

In upstream CERN/TIGRE (`81b6be2cc12ee630d36cba941e111ba14ba34c7c`), previous Julia-related patches (including PICCS fixes) have been fully merged upstream. Therefore, currently 0 patches are required.

If future upstream bug fixes or Julia-specific adaptations are needed, unified diff files (`*.patch`) should be placed in this directory and registered in `sources/manifest.toml`. They should also be mirrored to `bundled/patches/` in accordance with Yggdrasil's `DirectorySource` convention.
