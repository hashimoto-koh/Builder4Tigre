# patches/

Upstream CERN/TIGRE (`81b6be2cc12ee630d36cba941e111ba14ba34c7c`) にて、従来の PICCS 関連パッチが upstream に取り込まれたため、現在適用が必要なパッチは 0 件です。

今後 upstream に対して追加の修正や Julia 固有のバグフィックスが必要になった場合は、ここに unified diff (`*.patch`) を配置し、`sources/manifest.toml` に登録します。
また、Yggdrasil の `DirectorySource` 規約に従い、`bundled/patches/` にも同期します。
